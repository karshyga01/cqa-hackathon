# CLAUDE.md — правила для работы над этим проектом

Хакатон Freedom Broker CQA (оценка качества диалогов операторов). Полное описание, что сделано и что осталось: **docs/HANDOFF.md** — прочитай его перед любой работой.

## Как работать с пользователем
- Отвечай по-русски, коротко и просто, без воды.
- Делай **только то, что попросили**, по одному шагу. Новый шаг или идею начинай только по команде («делай»).
- Модель ИИ, провайдера, платные сервисы **не выбирай за пользователя**: покажи варианты честно, без рекламы, решает он.
- Не утверждай, что проверено, если не проверял. Цифры и факты — только проверенные.
- Оценки времени давай реальные для тебя (не «человеко-часы»).

## Чего нельзя
- Коммитить, пушить, делать репозиторий публичным — **только по прямой команде**.
- Класть в git `.env` (ключ OpenRouter) и папку `data/` (переписки клиентов, записи звонков). Они в `.gitignore` — не трогай эти правила.
- Ключ API никогда не выводить в ответах, логах и во фронтенд.
- Менять исходные транскрипты (текст и метки времени хранятся как пришли).
- Открывать сервер наружу (`HOST=0.0.0.0`, туннели, хостинг): входа по паролю нет, в данных переписки клиентов.
- Тратить деньги на ИИ без нужды: большие прогоны (все 65 диалогов и т. п.) — только с согласия; для проверок — 1–3 диалога.

## Перед изменениями и после
- `npm test` до и после правок (сейчас 136 тестов, все должны проходить).
- Изменения интерфейса проверять в браузере (компьютер и ширина телефона 390 px).
- Сервер без зависимостей (Node 18+): не добавляй npm-пакеты без согласования.
- Сервер запускать `node server/server.js` (или `npm start`), после правок сервера — перезапуск.
- Не ломать договорённости из docs/HANDOFF.md, раздел «Что нельзя ломать».
